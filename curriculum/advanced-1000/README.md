# 1000 道现成进阶战术题

来源：[Lichess 官方公开题库](https://database.lichess.org/#puzzles)，授权 CC0-1.0。利用本项目此前在 2026-10-01 下载的官方数据库前 64 MiB 压缩数据，扫描 1,343,564 条完整记录后自动筛选。没有自编局面，没有删子或移动棋子，没有生成新答案。

完整棋谱：`advanced-1000.pgn`。同时提供十份分主题 PGN、原始字段 `source.csv`、便于接入程序的 `index.json` 和验证记录 `validation.json`。

每个主题按题库评分从低到高排列；评分范围 600–1800，受欢迎度至少 90，已有至少 1000 次解题记录。评分不等于儿童适龄认证。白方题 497 道、黑方题 503 道。排除带 `mate` 标签的题及原有 100 题，并按完整题面（含执棋方、易位权及过路兵）去重。题目可能有多个主题，文件按其中一个官方主题归类。

PGN 从实际题面开始：先执行官方 CSV Moves 的第一步（对手铺垫着），保留其余官方解法。PGN 中 `Result` 为 `*`，因为做完战术题不意味着整盘棋已经结束。每题含官方题号、题目链接、原始对局链接、评分和全部主题。CSV 字段值保持原样。

验证：python-chess 检查原始局面和全部后续局面有效、所有铺垫着与答案着合法；另重新解析输出 PGN，逐题核对题面和走法与 index.json 一致。没有独立重新证明每题最优性或枚举所有防守分支，答案依据官方题库。此包是专项练习，不是完整注释教材。

如需现成的知识点教学，参见 [Lichess Practice](https://lichess.org/practice)：包括牵制、串击、双重攻击、闪击、关键格、对王，以及车残局等课程。Practice 的课程内容与公开题库不是同一份数据；本包不复制其课程注释，也不把公开题库的 CC0 授权套用到这些注释。
