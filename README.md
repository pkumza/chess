# 一起下棋 · 亲子国际象棋

原生 Android（Kotlin + Compose），中文、完全离线，无账号、广告和联网权限。

1.5.0：完整下载并扫描 Lichess 官方 6,100,952 道题，针对 5 岁半、学棋半年、刚学到王车易位的当前阶段，筛出 144 道交错进阶新题。从少子一步将杀热身，逐步加入吃子、升变、双重攻击、防守与两子配合；新主线没有连续三关使用同一种起手棋子。分五阶段，后段供成长后使用，不要求现在全部完成。原 100 题与完成记录保留，放在交错排序的“原题复习”。支持执黑自动朝向、官方战术解法终点通关；将杀题仍必须实际将杀。详见 [课程说明](curriculum/progression/README.md)。

挑战交互改进：合法但未完成目标的走法会先移动、停顿，再自动退回；不合法的落点会让棋子朝点击方向轻碰并弹回。棋盘内显示“↶ 再试试 / 换个格子”，随后用箭头提示可尝试的一步。预览不改变棋局和课程进度，也不播放成功落子或吃子音效。

按钮交互：按钮、关卡卡片、难度选项及辅助开关都有按压缩小与弹性回弹，点击播放轻柔的短气泡音。沿用“音效”开关及系统媒体音量，禁用按钮不触发声音或动作。音效由 `scripts/create_button_sound.py` 离线生成。

1.2.0：新增棋子平滑移动与落点回弹、吃子 8 碎片散落和光点效果；普通落子与吃子碎裂采用两种原创短音效，在落点处触发。侧栏顶部可切换音效，设置自动保存，跟随系统媒体音量。易位双子同步移动、吃过路兵在实际被吃位置碎裂；课程自动回应按顺序播放。返回、重开、悔棋、后台切换会取消旧动画与声音，不影响棋局结果。

1.1.0：对局页隐藏应用顶部栏并收起系统栏。棋盘占可用区域最大正方形；横屏操作区在右侧，竖屏在下方，状态和返回固定在操作区顶部。近方形分屏窗口通过角落“操作”按钮展开面板。

1.3.0：全部替换为 100 道来自 Lichess CC0 公开题库的实战残局将杀题（70 道一步、30 道两步），每题 4–7 枚棋子，均执白。原始局面不删子、不换位；每关可查看题目出处和原始对局。两步题逐一验证所有合法防守；接受所有满足指定步数的将杀解法，并走到实际将杀才完成。中文引导由本应用编写，这是一组残局将杀练习，不是完整的残局战略教材。

## 使用

- **一起下棋**：同屏轮流下；默认显示合法落点、将军和上一步，允许悔棋，可关闭亲子辅助。升变时选择后、车、象或马。
- **机器人陪练**：初学/练习两档，任选执色。机器人在后台限时搜索；悔棋回到自己上次落子前。
- **闯关学习**：144 道交错进阶新题，加原 100 道将杀题复习。每关有原题链接、逐级提示，可重试和复习。将杀题的所有合法防守均已穷举核对；非将杀题采用官方原解，未独立重新证明最优性。原 100 题完成记录保留，旧 24 关记录仍保存在本机，但不计为现有题通关。
- 棋局、设置和课程完成记录保存在本机。退出再进入即可继续双人或机器人棋局。退出课程后保存完成进度，未完成关卡从开局重新练习。

“申请规则和棋”区分当前局面与声明下一步走法后满足三次重复/50 回合的情况；五次重复/75 回合自动和棋，最后一步将杀优先。无棋钟。

## 构建

固定版本：JDK 17、Gradle 8.9、AGP 8.7.3、Kotlin 2.0.21、Compose BOM 2024.12.01、Android compile/target 35、min 26。开发工具在 `.tools/`，不修改全局 Java 配置。

首次准备工具运行 `./scripts/setup.sh`，并阅读 SDK 许可提示。现有工作区已准备完成。

```sh
./scripts/build.sh :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

项目使用 `chesslib/` 中保留源码和 Apache 2.0 许可的 Chesslib 1.3.4，避免运行时或构建时依赖 JitPack。所有 Gradle 依赖固定版本；首次构建需下载依赖，应用运行不需要网络。

家庭签名保存在 `.signing/family.jks`，密码保存在权限为 0600 的 `.signing/password`，均被 Git 忽略。请私下备份该目录；后续 APK 必须使用相同签名才可保留数据更新。不要将密钥和密码提交到公开仓库。源码压缩包不含私钥；在新机器上构建家庭更新版前须恢复该目录，仅试编译可运行 `./scripts/build.sh :app:assembleDebug`（调试签名不能覆盖家庭签名版本）。构建脚本读取本机密码，也可使用 `CHESS_KEY_PASSWORD` 环境变量。

安装：先确认 `./scripts/adb.sh devices -l` 中目标设备已授权，再执行 `./scripts/adb.sh -s SERIAL install -r artifacts/parent-chess-1.5.0.apk`，启动 `cn.parentchess/.MainActivity`。不要通过卸载或清数据处理签名冲突。

## 代码结构

- `ChessGame`：合法走法、历史、存档恢复与和棋规则。
- `ChessBot`：迭代加深的 negamax / alpha-beta；初学模式在相近分数候选中随机选择。
- `LessonAttempt`：预验证分支、错误走子回退、分类题与完成状态。
- `ChessViewModel`：后台搜索取消、过期结果隔离、双人/机器人独立存档、课程进度。
- `MainActivity`：自适应平板界面；棋子采用随包字体并加轮廓，确保离线显示。

## 课程与验证

`curriculum/lichess-puzzles.csv` 保存直接从官方数据库提取的 100 行原始记录，`selection.json` 保存选题顺序。`scripts/create_lessons.py` 根据官方格式先执行第一步（对手的铺垫着），再导入题面，绝不修改棋子。用 python-chess 穷举所有一步将杀；两步题对每个候选第一步检查对手的每一种合法防守，并收录全部将杀续着。终点必须是将杀，逼和或仍可继续的局面不能算成功。

[逐题来源与选题说明](curriculum/README.md)、[机器验证记录](curriculum/validation.json)、[原题 PGN](curriculum/selected-puzzles.pgn)。旧的自编 24 题仅归档于 `curriculum/legacy-original-24.json`，不再打包进应用。

```sh
PYTHONPATH=.tools/python-chess python3 scripts/create_lessons.py
./scripts/build.sh :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

运行时以独立的 Chesslib 再次测试 100 个来源局面、原题解法、所有合法防守及替代将杀着。另保留基础规则、机器人、存档和移动动画测试。旧的 `smoke_play.py` / `check_move_effects.py` 使用 1.2 版自编关卡名称，仅适用于旧版本；1.3 版使用 `check_sourced_lessons.py`。

## 当前边界

自动死局识别覆盖确定的子力不足情形：裸王、王象/王马对裸王、仅有同色格象。不会错误地把王双马对裸王或王马对王马判为死局。**任意封闭兵链等复杂死局尚无完备判定**，因此目前不能声称覆盖 FIDE 所有理论死局；可使用双方同意和棋。第一版机器人面向亲子入门，不提供棋力等级承诺或专业复盘。
